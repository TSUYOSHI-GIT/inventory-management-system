# Система учета товаров (inventory-management-system)

Консольное приложение для управления складскими запасами.  
Писал его для портфолио и чтобы на практике воспользоваться архитектурой, тестами и генераторами в рамках единого проекта.

## Что умеет

- Просматривать все товары на складе
- Искать товар по id, категории или ключевым словам (через генераторы)
- Принимать товары (если товар уже есть — количество увеличивается)
- Отгружать товары с контролем остатков (нельзя отгрузить больше, чем есть)
- Показывать товары с низким остатком
- Все данные хранятся в JSON-файле, программа сама его создает при первом запуске

## Стек

- Python 3.14+
- ООП, dataclasses, кастомные исключения
- Сохранение в JSON (os, json)
- Генераторы для поиска
- Тесты на pytest

## Как запустить

```bash
# Клонировать репозиторий
git clone https://github.com/TSUYOSHI-GIT/inventory-management-system.git
cd inventory-management-system

# Установить зависимости (только pytest для тестов)
pip install -r requirements.txt

# Запустить приложение
python -m app.cli
